먼저 ⚙️ 설정에서 Apps Script URL을 등록하고, ➕ 시트 추가로 요약할 시트를 등록하세요.

⚙️ 설정

시트를 읽어오는 Apps Script Web App URL을 입력하세요. (키는 저장되지 않으며 이 URL만 사용)

➕ 시트 추가

붙여넣으면 시트 ID를 자동 추출합니다.

범위의 첫 줄이 머리글이 됩니다. A1:H200 · B:F(열만) · A5:(5행부터) · 3:100(행만) 형태로 적습니다.
탭 이름은 Apps Script가 tab 값을 지원할 때만 적용됩니다. 범위는 스크립트가 지원하지 않아도 받아온 뒤 잘라서 보여줍니다.

시트마다 따로 정합니다. 금액관리를 고른 시트에서만 특별 화면이 나오고, 나머지는 양식이 같아도 시트 내용을 그대로 보여줍니다.

금액 · 수수료 · 합계 · 송금액 · 잔액 · 단가처럼 금액을 뜻하는 머리글의 칸에만 적용됩니다. 주차 · 박스 같은 숫자 칸과 날짜 칸은 그대로 둡니다.

표시할 컬럼 선택

대시보드에 보일 컬럼만 체크하세요.
